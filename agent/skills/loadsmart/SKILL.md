# Loadsmart ABM skills

Each skill lives in its own folder under this one. Use `loadsmart-abm-orchestrator` first: it runs the pipeline in order and says which step to call next.

- `loadsmart-abm-orchestrator`: daily and weekly pipeline order
- `la-signal`: buying signals per account
- `la-persona-enrich`: contact and persona enrichment
- `la-research`: account research
- `la-email`: first-touch email drafts
- `la-sequence`: sequence build and enrollment
- `la-daily-report`: daily pod report
- `la-list-qa`: list quality checks
- `la-crm-audit`: Salesforce data audit
- `la-abm-tag`: weekly ABM account tagging
- `la-pod-feedback`: pod feedback loop
