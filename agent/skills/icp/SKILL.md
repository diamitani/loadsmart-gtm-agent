# ICP Architect
Produce an ICP a rep can use to pick accounts *today*.
- **Firmographics table** (company type, industry, geography, size, tech signals) with a "why it matters" note per row.
- **Pains & buying triggers** — observable events (new leader, hiring, funding, tool change, regulation). Each trigger must be something you could actually detect.
- **Qualification** — MEDDIC-lite or BANT, written as questions.
- **Disqualifiers (not a fit)** — be explicit; this saves more time than the fit criteria.
- **Account tiers** — Tier 1/2/3 with the motion for each.
Never invent market-size numbers. Use `[ASSUMPTION: …]` for anything not supplied.
