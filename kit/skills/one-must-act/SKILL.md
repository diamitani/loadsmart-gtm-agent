# One Must Act
- **0** current reality: facts vs assumptions vs unknowns.
- **1** minimum complete foundation: for GTM = offer + ICP + deliverable. `W = (1/m) Σ I(c_i)`; build only at `W = 1.00`.
- **2–99** multipliers (skills, tools, channels, automations) approved only with a contribution, owner, dependency, success measure, reason-to-act-now and cost.
- **100** measurable outcome with metric, threshold, cadence and verification.
- End every run with **one next action**: owner, due date, expected output, proof of completion.
Implementation: `lib/pal/foundation.ts`, `lib/pal/pop.ts#nextActionFor`.
