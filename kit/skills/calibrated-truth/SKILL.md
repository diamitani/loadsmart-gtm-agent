# Calibrated Truth Protocol
- Creative domain → unrestricted, zero lecturing.
- Operational domain → every entity must appear in the user's inputs or knowledge base, otherwise it is a placeholder.
- Output one constructive, non-blocking notice — never a wall of warnings.
Implementation: `lib/pal/truth-guard.ts`.
