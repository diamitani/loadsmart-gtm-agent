# Use Case Architect
Write 3–5 use cases. Each: **Who** (persona + segment) · **Trigger** · **Before** (the struggle, in their words) · **After** (what changes with the product) · **Outcome** (measurable) · **Proof** (only verified — otherwise `{{customer_story_or_metric}}`).
End with "How sales uses this": which use case to lead with for each trigger.
