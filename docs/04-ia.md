# 04. Information Architecture: Loadsmart GTM Agent OS

## 1. Domain Object Hierarchy

| Object | Definition & Role | Key Attributes |
|---|---|---|
| **Pod** | Hybrid AE/SDR sales team unit (e.g. Mid-Market East, Opendock Specialist). | `id`, `name`, `target_product`, `lead_ae`, `lead_sdr`, `daily_target_accounts`, `active_mailboxes` |
| **Account** | Target enterprise shipper or facility operator. | `id`, `pod_id`, `name`, `domain`, `industry`, `est_freight_spend`, `facility_count`, `incumbent_tms`, `icp_score`, `stage`, `status` |
| **Contact** | Verified decision maker mapped to an account. | `id`, `account_id`, `name`, `title`, `persona_type`, `email`, `email_status`, `phone`, `linkedin_url` |
| **Signal** | Observable "why now" trigger event. | `id`, `account_id`, `source`, `signal_type`, `headline`, `timestamp`, `relevance_score` |
| **Touchpoint / Copy** | 1-to-1 message drafted for a contact. | `id`, `contact_id`, `channel`, `step_number`, `subject`, `body_text`, `proof_point_cited`, `approval_status` |
| **Sequence** | Multi-channel outreach plan (Gong / Amplemarket / Apollo). | `id`, `account_id`, `sequence_template`, `scheduled_date`, `status`, `events` |
| **Mailbox** | Secondary sending inbox connected to warmup & rotation pool. | `id`, `pod_id`, `email_address`, `domain`, `provider`, `daily_cap`, `sent_today`, `warmup_status`, `health_score` |
| **PipelineRun** | Daily or scheduled execution instance of the 10-step engine. | `id`, `run_date`, `stage`, `accounts_processed`, `leaks_flagged`, `duration_ms`, `w_score` |

## 2. Global Navigation Grammar

- **Executive Navigation Bar:**
  - **Overview (`/`):** Mission command, active pods summary, system readiness badge.
  - **Pod Dashboard (`/dashboard`):** Real-time funnel, pod filter, leak flags, stuck accounts, mailbox health, CSV import/export.
  - **Live Copilot (`/copilot`):** Vercel AI SDK v7 streaming agent swarm with tool execution and approval drawers.
  - **10-Step Pipeline (`/pipeline`):** Daily deterministic pipeline execution controller (`la-crm-audit` to `la-daily-report`).
  - **Sales Playbook (`/playbook`):** Interactive Playbook v2, battlecards, persona maps, claims library.
  - **Automations Hub (`/automations`):** n8n workflows, Clay schemas, Salesforce fields, export center.
  - **Settings (`/settings`):** API connectors, mailbox pools, Supabase / Cloudflare integration status.
